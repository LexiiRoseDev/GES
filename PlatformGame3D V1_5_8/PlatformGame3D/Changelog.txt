V1_1 Buttons Buttons and more Buttons!
======================================
Added buttons to control anything using a switch on switch off interface

Reworked rotating bars to inherit from a single rotating pin object for faster itteration and implementation of interface.
Reworked Jump Pad into a single version to allow for faster itteration and implementation of interface.
Added particles to the jump pad to indicate active state.
Reworked crystal to implement interface and allow faster itteration.
Removed Physics crystals for simplicity, to be re-added later.
fixed cyrstals colliding with the player, players no longer bump into floating crystals.
fixed players momentum upon respawning, players no longer keep any momentum from previous life when respawning.
